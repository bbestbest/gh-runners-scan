Permissions needed
Fine-grained token (recommended)
  • Resource owner: the organisation, not your user
  • Repository access: All repositories (or the ones to watch)
  • Repository permissions → Actions: Read-only
  • Metadata: Read-only is added automatically
  • The organisation may have to approve it
Classic token (broader: full access to private repos)
  • repo scope; add read:org to list your organisations
  • If the organisation uses SSO: Configure SSO → Authorize
