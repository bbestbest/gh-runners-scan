Permissions needed
Fine-grained token (recommended)
  • Resource owner: the account that owns the repos
  • Repository access: All repositories (or the ones to watch)
  • Repository permissions → Actions: Read-only, or Read and write to cancel and re-run
  • Metadata: Read-only is added automatically
  • The owner may have to approve it
Classic token (broader: full access to private repos)
  • repo scope; add read:org to list more owners
  • If SSO is required: Configure SSO → Authorize
Create a fine-grained token ↗

At least 8 characters, or . It encrypts the token (AES-GCM); this page never stores it. Chrome can save it as "gh-runner" and fill it in when you unlock.

Sent only to api.github.com. Without "Remember" it stays in this tab's memory only.
